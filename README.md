# Banking System

A simple Java-based Banking System that allows users to perform basic banking operations through a console interface.

## Features

* Create a bank account
* Deposit money
* Withdraw money
* Check account balance
* View account details
* Generate an account number

## Technologies Used

* Java
* Scanner
* Conditional Statements
* Switch Statement
* Methods

## How to Run

1. Clone or download the repository.
2. Open the project folder in VS Code.
3. Open the terminal.
4. Compile the Java program:

```bash
javac BankingSystem.java
```

5. Run the program:

```bash
java BankingSystem
```

## Project Type

Console-based Java application.
